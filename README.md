# 勇氣寶庫

獨立使用的親子獎賞遊戲：家長送抽獎券，小朋友開寶箱、翻卡收集獎賞。毋須安裝或完成勇氣城堡。

## 開始使用
1. 右上角「家長」設定 4–8 位數字密碼。
2. 在獎賞頁新增或修改獎賞，再到「抽獎券」填原因及送券。
3. 小朋友點寶箱三次、翻開卡牌；集齊碎片會自動合成。
4. 家長在兌現頁確認已給予的獎賞。

保留寶物袋、圖鑑、紀錄、音效、動畫與備份還原。資料只存在目前瀏覽器，請定期備份。與原城堡寶庫同用 GitHub Pages 網域時共用存檔；不同網域或裝置請用備份還原。

## 開發
純靜態 HTML/CSS/JavaScript；GitHub Pages 使用 main 根目錄。`npm ci` 後執行 `npm test`；`npm start` 本機預覽。來源為 Courage-Castle 的勇氣寶庫，原專案保持完整。
